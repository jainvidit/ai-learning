# ADR-0001: Hosted Edition (Phase 5) is not scheduled — parked awaiting owner authorization

**Status:** accepted (genesis, 2026-07-25) · **Item:** ROOT.6 · **Trigger:** OPEN-QUESTIONS #6

## Question
The owner never explicitly ratified keeping a Hosted Edition (ASSUMPTIONS.md #32 [INFERRED]).

## Readings
- **A:** Phase 5 stays designed-but-optional and may be scheduled (blueprint's position).
- **B:** "personal desktop tool, not a production service" (CONSTRAINTS.md #15 [HARD]) means hosted work is not scheduled at all without a fresh directive.

## Decision
**Reading B.** ROOT.6 exists in the ledger (traceability to hosted-edition.md) but is
`blocked: awaiting_human_authorization` and is never decomposed or dispatched. Hosted
work is additionally tier-3-adjacent (public API surface, auth, paid resources — PART 9
Rule 2 hard stops), so even Reading A could not execute it autonomously.

## Reasoning
Least irreversible: not building is trivially reversible; building against an
unratified directive is wasted verified work. Most consistent with adjacent shards:
CONSTRAINTS #15 is [HARD]; the hosted-edition shard itself says "see OPEN-QUESTIONS #6
before scheduling any of this work."

## If the other reading is correct
Unblock ROOT.6, decompose per hosted-edition.md; all edition-invariant interfaces
(ExecutionDriver, event/projection model, Profile shape) are built anyway, so no rework.
