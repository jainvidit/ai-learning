# ADR-0010 — ASSUMPTIONS #12 discharged negative: Bedrock structured outputs unsupported; judge pipeline uses tool-schema enforcement with validate-and-repair

**Status:** accepted (autonomous, PART 9 Rule 1)
**Item:** ROOT.1.9 (Probe), evidence `.program/audits/probes-bedrock-structured-outputs.md`
**Consumers:** ROOT.2.3 (judge/calibration engine — MUST read this before dispatch), ROOT.1.5 (ModelGateway seam), ROOT.1.2 (model-router interface doc)
**Date:** 2026-07-25

## Finding

Two live probe calls against this repo's existing Bedrock setup: basic connectivity
SUCCEEDS; `output_config.json_schema` FAILS with
`400 invalid_request_error: output_config.json_schema: Extra inputs are not permitted`
(request id recorded in the evidence doc). Tier-0 verification confirmed the evidence is
a real recorded exchange and that the probe modified nothing in `src/`.

## The two readings

1. **Wait for platform support** — treat structured outputs as temporarily unavailable
   and block judge-pipeline design on it.
2. **Design for its absence now** — REQ-JP-01 requires schema-conformant judge output,
   not any specific API feature. Enforce schema via (a) tool-use forcing (define one tool
   whose input schema IS the judge schema; force its invocation), falling back to
   (b) prompt-embedded schema + local zod/ajv validation + one bounded repair re-ask.

## Decision

Reading 2. It is least-irreversible: if native structured outputs later appear, swapping
the enforcement mechanism is internal to the ModelGateway seam and invisible to every
consumer. Blocking Phase 1 on a platform feature with no announced timeline is a stall,
which PART 9 Rule 1 forbids.

## Consequences

- The ModelGateway seam contract (ROOT.1.5 / model-router interface doc) must expose
  `requestStructured(schema)` as a seam-level capability whose implementation is
  tool-forcing + validate/repair, NOT a passthrough of `output_config`.
- ROOT.2.3's calibration engine budgets for at most ONE repair round-trip per judgment;
  a second failure is a judge error surfaced per the shard's error path.
- ASSUMPTIONS #12 must not be cited as live; any item that assumed native structured
  outputs cites this ADR instead.
- DECISIONS-PENDING row 15 records this for owner visibility; not blocking.
