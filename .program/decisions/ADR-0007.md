## Rejected — with reasons

- **Re-level Gates to Capability (sizing #5a).** Rejected: Gate stays a leaf type with a
  recorded point-5 exemption; per-behavior expressiveness comes from checklist *rows*
  with per-row evidence, not from item sprawl. A failing row still halts the phase.
- **Raise ROOT.5.5 to Phase level (sizing #2, one option).** Rejected: ledger depth is
  unbounded; per-module Capabilities under 5.5 preserve the phase model without renumber
  churn. The sizing concern is met by the decomposition rule, not the level.
- **Separate dependency-steward item for package.json in Phase 0 (coupling #3, one
  option).** Rejected in favor of machine-readable depends_on serialization within
  Phase 0 and ROOT.7.1 ownership afterward — a standing queue item would bottleneck a
  phase that is already serialized by its edges.
- **ROOT owning `.program/**` (coupling #25).** Accepted as-is: the director is the
  ledger custodian; interface docs get named-file protection via ROOT.1.2/7.1 globs.
- **Treating REQ-CP-04's "no app redeploy" as a criterion (sizing #31).** Restated as
  bundle-immutability + versioned static route; the CDN framing is hosted-edition scope.

Every note-level fix (interim-renderer handoff, dock tab extensibility, celebration API
reuse in 5.2, content.ts module-state layering) is recorded in the affected item bodies —
coordinators inherit them from their own files, not from this ADR.
